# Research Documentation: VoiceShield AI

This directory houses the academic, mathematical, and algorithmic research underpinning the **VoiceShield AI** acoustic deepfake detection platform.

## Directory Structure
- `synopsis/`: Project synopsis, threat landscape, problem statement, and defense objectives.
- `literature-review/`: Comprehensive review of modern neural TTS/VC architectures, ASV limitations, and existing detection techniques.
- `methodology/`: Dual-stream neuro-acoustic architecture, glottal pulse physics, and LFCC feature engineering.
- `datasets/`: Dataset curation protocols, Indian linguistic accents, and cellular telephony degradation benchmarks (AMR-WB/VoLTE).
- `references/`: Complete bibliography and academic citations.
