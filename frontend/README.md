# VoiceShield AI - Frontend Command Center

Modern, high-performance React + Vite user interface for real-time acoustic inspection, live microphone streaming, and forensic file analysis.

## Key Features
- **Microphone Analysis:** Live Web Audio API stream capture, VU level metering, and real-time WebSocket communication with backend inference.
- **Recorded Audio Analysis:** Drag-and-drop validation for WAV, MP3, and WebM recordings with segment-level forensic timelines.
- **Systematic Design System:** Professional dark/light theme tokens and modular components (<150 lines per file).

## Development
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```
